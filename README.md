# PC Tycoon: project showcase

A one-page showcase of **PC Tycoon**, a first-person PC-building shop sim I am making solo in
Unity 6. It shows the game the way a store page would, and how it is built: my workflow, the
tools I use and the systems I created.

**Live page:** https://alonlevy01.github.io/pctycoon-showcase/

The game's source code is private; this repository holds only the page and its screenshots.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

## Publish (GitHub Pages)

Settings > Pages > Deploy from a branch > `main`, folder `/ (root)`.
