How it's made One developer, an AI-assisted workflow, and a lot of automation

I design the game, make the calls and review every change. I use Claude Code as a development partner, and I built the project so that an agent can work on it safely: it can drive the open Unity editor, run a full playtest and show me what changed, without ever touching my screen.

~68klines of C#, editor tools and game code
90PC parts, every 3D model generated from code
650checks in the automated playtest, run before every commit
160+commits across 30+ focused work sessions
Short task→Proposal→Implement→ Compile + self-tests→Automated playtest→Before / after shots→Review + commit

1Written down, so anyone can pick it up

A handbook, a roadmap and design docs that any developer, human or AI, reads first. Each session starts from where the last one ended and leaves notes for the next.

2Drive the editor without a screen

A small request protocol lets scripts ask the running Unity editor to compile, rebuild scenes, render snapshots or run tests, and read back a short status.

3Test the way a player plays

An automated Play-mode playtest takes the game through real jobs end to end, from the first email to the shipped PC and the move to a new store, and captures screenshots along the way.

4Look, don't guess

Every visual change is judged from rendered before / after snapshots and contact sheets, not from reading code.

5Rules that protect the work

Generated content and hand-placed content are kept apart, so code never overwrites what I placed by hand. Changes to my own edits go through versioned migrations.

6Spend tokens like money

The tooling summarises logs, status and test results into a few lines, so an AI session spends its budget on the work, not on rediscovering the project.

What I built Systems and tools I made for this project

Every part below is a 3D model generated by code from its spec: real dimensions, bevelled edges, small hardware and moving pieces that open and close on real hinges.

Procedural PC part generator

Motherboards, graphics cards, coolers, cases, PSUs, RAM and more, built mesh by mesh to per-category triangle budgets, plus a retail box for each. A hinge checker sweeps every moving piece open to prove it clears everything around it.

Automated playtest and self-tests

Hundreds of end-to-end checks in Play mode, plus rule and assembly self-tests that run on every recompile.

Economy simulator

Simulates 60 in-game days of real offers judged by player bots, to tune prices and payouts before anyone plays.

Local text-to-3D pipeline

Props and vehicles the asset packs lack come from my own local pipeline: text to image to 3D, then cleaned up, sized and exported in Blender with LODs, ready for Unity.

Scene builders

Code builds the shops, streets and fixtures at real human scale, and rebuilds them without touching anything placed by hand.

In-game UI kit

A consistent look across menus, the desk websites, the skill wheel, build mode and the logo designer: read little, understand most.
